# 🌌 Solar System Explorer

An interactive web experience that lets you explore different worlds through planet information and simple navigation controls.

🔗 **Live Demo:** [Explore the Solar System](https://2-ritam.github.io/solar-system-explorer/)

## ✨ Features

- 🌍 Explore information about different worlds.
- 🪐 Navigate between worlds using the **Next World** control.
- 🎲 Discover a world using the **Random World** feature.
- 🔊 Toggle sound on or off.
- 🚀 Access the experience directly through a web browser.

## 🚀 Getting Started

You can explore the project online using the live demo link above.

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/2-RITAM/solar-system-explorer.git
   ```

2. Open the project folder:

   ```bash
   cd solar-system-explorer
   ```

3. Open `index.html` in your web browser.

No additional build tools are required for this static webpage.
